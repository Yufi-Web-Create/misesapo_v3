# 11. 完成条件（Definition of Done）

このファイルは実装の進行に伴い、コマンドと実際の結果で随時更新する。最終監査時に全項目を再実行し結果を記録する。

## チェックリスト（初期状態: 未検証）

- [ ] クリーン環境でREADMEの手順により起動できる
- [ ] .env.exampleに必要変数と説明がある
- [ ] 秘密情報なしでモックモードの主要フローが動く
- [ ] 公開サイト、顧客、管理者の主要画面が実装済み
- [ ] 登録、ログイン、ログアウト、保護ルートが動く
- [ ] 顧客が相談を開始し、案件が生成される
- [ ] 司令塔AIが構造化タスクを作り、状態を進める
- [ ] 相談→要件→見積→承認→制作→QA→共有→修正→再QA→顧客承認→管理者公開承認→納品を架空案件で完走できる
- [ ] 人間承認なしに金額確定・課金・外部重要送信・本番公開・削除・最終納品が行われない
- [ ] 顧客Aが顧客Bのデータを閲覧・変更できない
- [ ] 案件ごとの内部チャットが混在しない
- [ ] 実動プレビューが案件・版ごとに隔離される
- [ ] 公開済み成果物を上書きできない
- [ ] 赤ランプが正しい理由で点灯し、理由解消時だけ消える
- [ ] 型・lint・単体・統合・E2E・buildが成功
- [ ] 重大・高リスクの既知脆弱性がない
- [ ] 主要画面に明白なアクセシビリティ違反がない
- [ ] エラー・空・読み込み・権限なし・再試行状態がある
- [ ] 監査ログで重要操作を追跡できる
- [ ] AI/外部サービスの費用上限・再試行上限・緊急停止が動く
- [ ] セットアップ・テスト・運用・バックアップ・復旧・本番接続手順がある
- [ ] 未実装のTODO・ダミーボタン・偽の成功表示・未接続の重要画面が残っていない
- [ ] VERSION、CHANGELOG、リリースノートが更新されている
